**Date:** October 2026

---

## 1. Route & Component Architecture

- **Route:** `/benchmark` (accessible via authenticated workspace sidebar)
- **Component:** `TrustForge Frontend/src/pages/app/ModelBenchmarkPage.tsx`
- **Backend API Endpoints:**
  - `GET /api/benchmark/models`: Returns candidate model metadata & real-time credential entitlement.
  - `GET /api/benchmark/latest`: Returns latest empirical benchmark run from `durableStore`.
  - `POST /api/benchmark/run`: Re-runs the full 10-model evaluation against active target evidence.
  - `GET /api/reports/demo_benchmark_run/pdf`: Downloads formatted compliance benchmark PDF.

---

## 2. Dashboard UI Capabilities

### 2.1 Research Header & Transparency Notice
- Displays the active RAG legal corpus version (`83 Chunks - Act 2023 + Notified Rules 2025`).
- Displays the cryptographic RAG context snapshot hash (`b9cec843...`).
- Renders the **Gate J Transparency Notice**: Explicitly notifies reviewers that M01, M02, and M03 run live on Groq LPUs, while M04–M10 require additional API keys or local weights, avoiding any misrepresentation of partial benchmarks as complete.

### 2.2 Top-3 Majority Voting Consensus Banner
- Shows the synthesized consensus score (e.g. `82.5 / 100`) and posture (`Strong Alignment`).
- Documents the voting mechanism across the top 3 live-verified models (`M03`, `M01`, `M02`).

### 2.3 Empirical Evaluation Matrix Table
- Lists all 10 candidate models.
- Displays Model ID, Architecture & Provider, Trust Score, Accuracy %, Macro F1, Grounding Rate %, and Average Latency.
- Live verified models display green "Verified Active" badges; blocked models display amber "Requires Key" or grey "Unavailable" badges.
- Displays `—` for Trust Score and metrics on blocked models rather than fake zeroes or fabricated estimates.

### 2.4 Model Inspection Drawer
- Selecting any model card displays its architectural breakdown, active parameter footprint, grounding adherence commentary, and remediation quality.

### 2.5 Machine-Readable Exports
- **CSV Download Button**: Generates a standard RFC 4180 CSV containing all 10 model metrics for import into Python/R scientific analysis tools.
- **PDF Report Button**: Downloads the multi-page executive compliance benchmark report generated by the Express API.
