## 2. Critical Deficiencies Requiring Immediate Action

1. **Scoring Taxonomy Mismatch:** The existing engine scores 6 pillars across 20 proprietary controls. The faculty demands evaluation over **C1–C10 obligation categories**.
2. **Ungrounded Verdict Leakage:** When an LLM cites a non-existent provision or invents an evidence quote, existing code logs the error but still allows the verdict to influence the Trust Score. Under the faculty methodology, failed verdicts **must be converted to `Not determinable` and dropped from scoring ($A_i = 0$)**.
3. **Retrieval Depth Truncation:** `hybridRAG.ts` defaults to $top\_k = 3$, whereas the methodology prescribes **$top\_k = 5$** (with $k=3$ and $k=8$ reserved for ablation).
4. **Missing Penalty-Proportional Weights (W1) and Gating Cap:** The code lacks the mandated ₹1,000 cr penalty weighting scheme and the $\min(TS, 40)$ critical failure cap for sites without HTTPS or privacy policies.
5. **Absence of TOPSIS Engine:** Model selection currently uses heuristic sorting rather than formal TOPSIS multi-criteria analysis.
