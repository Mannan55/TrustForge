TRUSTFORGE - LOCAL STARTUP INSTRUCTIONS (WINDOWS)
=================================================
Project: C:\TF new V1\TrustForge

OPTION A - ONE CLICK
--------------------
1. Double-click Start_TrustForge.bat.
2. Keep the two new Command Prompt windows open.
3. Open http://127.0.0.1:5173 in your browser.
4. Backend health: http://127.0.0.1:8000/api/health
5. API docs: http://127.0.0.1:8000/docs

OPTION B - MANUAL COMMANDS (TWO SEPARATE CMD WINDOWS)
---------------------------------------------------
Window 1 (backend):
cd /d "C:\TF new V1\TrustForge\backend"
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000

Window 2 (frontend):
cd /d "C:\TF new V1\TrustForge\TrustForge Frontend"
npm run dev -- --host 127.0.0.1 --port 5173

STOPPING
--------
Press Ctrl+C in both command windows.

NOTES
-----
- Python, FastAPI, Uvicorn, Node.js, npm and frontend dependencies
  should already be installed from your existing setup.
- Do not run npm install every time; only when dependencies change.
- The backend accesses the SQLite database automatically.
- Keep the existing backend .env configuration in place for AI features.
- If port 8000 or 5173 is already in use, an instance may already be running.
